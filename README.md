# 📊 Sales Analytics Dashboard

## 📌 Project Overview

This project analyzes sales performance using SQL, Power BI, Excel, and Python to help businesses understand revenue trends, customer behavior, product performance, and regional sales. The project includes data cleaning, SQL analysis, KPI calculations, and an interactive Power BI dashboard for business decision-making.

---

## 🎯 Objectives

- Analyze sales performance across different regions, states, and cities.
- Identify top-performing products and customers.
- Measure profitability and profit margins.
- Track monthly, quarterly, and yearly sales trends.
- Evaluate customer purchasing behavior.
- Monitor payment modes and shipping performance.
- Build an interactive dashboard for business insights.
